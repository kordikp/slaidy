### 14. `[S]` Take it with you

*Summary:* The exits, because a format you cannot leave is a trap.

*Text:* 125%

| | |
|---|---|
| **PDF** | the browser's own print engine, one page per click; nothing is uploaded |
| **Markdown** | the folder you started with: `slides/*.md` and `figures/*.svg` |
| **One HTML file** | the deck inside the editor: opens from a disk, presents from a link |
| **An article** | the whole deck as text with its figures, for Substack or a `.docx` |
| **The web** | `publish.py` makes a link that presents, and the notes as a page |
| **GitLab** | a deck published there saves straight back, as markdown, under your name |
